# SENTRANET Benchmark Dataset Provenance (Phase 10)

This document establishes the official provenance, local file status, checksums, schemas, and label mappings for all benchmark datasets evaluated in SENTRANET.

---

## 1. Scientific Integrity and Provenance Policy

SENTRANET strictly distinguishes:
- **Category A: Authentic Public Benchmark Captures** (`CICIDS2017`, `UNSW-NB15`, `CIC-DDoS2019`).
- **Category B: Synthetic Development Fixtures** (`sample_network_traffic.csv`).

Under no circumstances is a synthetic development fixture ever represented as real benchmark performance. Furthermore, real benchmark datasets are only marked as evaluated if authentic files have been downloaded and verified in `data/raw/<dataset>/`.

## 3. Preprocessing and Feature Extraction Versioning

- **Pipeline Version:** `1.0.0`
- **Temporal Aggregation Window:** Exactly 60 seconds (`dt.floor("60s")`).
- **Rolling Window Lookback:** Exactly 5 completed windows ($K=5$, `min_periods=1`).
- **Canonical Feature Count:** Exactly 17 numerical continuous features.
- **Model Invariance:** Models (XGBoost, Isolation Forest, Scaler) remain strictly frozen without benchmark-specific retraining.
